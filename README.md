# EMR (but its a TUI)

# How it was made

## Stack
- python
    - textual
    - sqlite
Basically that much only!

`sql.py` contains the sql stuff \
`main.py` contains the textual stuff

# How to use

- Clone the repo

```
git clone https://github.com/dorkishguy/EMR.git
```

- run it!

```
python main.py
```

# For server

- Run

```
python serve.py
```

- Open `localhost:8000` in your browser
